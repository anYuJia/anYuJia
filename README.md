我喜欢从想法出发构建实用的软件，关注 AI 开发工具、全栈应用和跨平台体验，也持续通过开源项目探索新的工程实践。

- 🔭 **当前专注于**：AI 应用、Coding Agent 与开发者工具。
- 🧩 **项目方向**：Rust 系统工具、TypeScript 产品和跨平台应用。
